Rabbit Hole is an App Store app for iPhone and iPad. It also works with a Russian Apple ID region.
It is an alternative to [Koala Clash](/faq/koala-clash/) if you would rather not install TestFlight.

<Aside type="note">
  On Android, install [Koala Clash](/faq/koala-clash/) — we recommend Rabbit Hole for iOS only.
</Aside>

## Add the subscription

In your account, press **Install** → iOS → Rabbit Hole and press the add subscription button. If it
does not work, copy the link and add it in the app manually.

## Update the subscription

Tap the icon with four squares → **Update**.

## The Connect button switches off right away

Read the message under the button. Most often it is the
[device limit](/faq/subscription/#device-limit): remove extra devices in your account and update the
subscription. If the subscription has expired, renew it in your account.

## Logs

Support needs logs when a particular service does not open:

1. Open the second tab → **Logs**.
2. Set the level to **Info** (the “Silent” level records almost nothing).
3. Open the problematic service, go back to the logs and save them to a file.

If the file does not go through in the chat, send screenshots or upload the file to cloud storage
and share the link.
