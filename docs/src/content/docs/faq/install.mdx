## How to connect

<Steps>

1. Open your account: the Telegram bot [@teamdominant_get_bot](https://t.me/teamdominant_get_bot)
   or the website [infra.dominants.link](https://infra.dominants.link).

2. On the main page, press **Install** and pick your platform.

3. Install the app from the link in the instructions.

4. Add the subscription with the **Add subscription** button — it opens the app for you. If the
   button does not work, press **Copy link** and paste the link into the app manually.

5. Turn the VPN on. If something is off, see [Something is not working](/faq/troubleshooting/).

</Steps>

<Aside type="caution">
  The subscription link is your personal access key. Do not publish it or send it to strangers: every
  new app that uses it takes a slot in your device limit.
</Aside>

## Which app to use

| Platform | We recommend |
| --- | --- |
| iPhone, iPad | [Koala Clash](/faq/koala-clash/) (via TestFlight) or [Rabbit Hole](/faq/rabbit-hole/) (App Store) |
| Android | [Koala Clash](/faq/koala-clash/) or [FlClashX](/faq/flclashx/) |

| macOS, Linux | [Koala Clash](/faq/koala-clash/) |
| Android TV, Google TV, TV boxes | Koala Clash (APK file) |
| Router | See [Routers](/faq/routers/) |

The up-to-date list, with direct download links, is always in the **Install** section of your account.

### Why not Happ, NekoBox or Throne

We do not support these apps: they have many issues whose causes only their developers know, so we
cannot guarantee they work reliably. Happ sometimes keeps working after a profile update, but if
anything goes wrong, switch to Koala Clash or Rabbit Hole first.

When you switch from another app, delete the subscription from the old one — otherwise it keeps
taking a slot in your [device limit](/faq/subscription/#device-limit).

## iPhone and iPad

**Koala Clash** is distributed through TestFlight, Apple's official app for test builds.

<Steps>

1. Install [TestFlight](https://apps.apple.com/app/testflight/id899247664) from the App Store.

2. In the install instructions, press the button that adds Koala Clash to TestFlight. It opens
   TestFlight with the invitation — there is no code to type in.

3. Install Koala Clash in TestFlight and add your subscription.

</Steps>

If Koala Clash stopped opening, a new build has most likely been released while automatic updates
are off: open TestFlight and update the app. If TestFlight was deleted, go through the steps again.

**Rabbit Hole** installs straight from the App Store and works with a Russian Apple ID region too —
there is no need to change the region.

## Android without Google Play

Koala Clash and FlClashX are not published on Google Play, so on any Android device — including
Huawei and Honor with HarmonyOS — you install them from the APK file linked in the instructions. If
the system asks, allow installing from unknown sources for your browser or file manager.

## TV and TV boxes

On Android TV, Google TV and boxes such as Xiaomi Mi Box, install the Koala Clash APK file:

- if the TV has a browser or a file manager, download the APK right on the device;
- if not, copy the APK to a USB stick, plug it into the TV and install it from the file manager.

The easiest way to add the subscription is the QR code in the instructions. Alternatively, type the
link with the remote or a connected keyboard.

## Linux

On Linux with a desktop environment (GNOME, KDE and so on), install Koala Clash. Headless servers
can run it in Docker — there is no ready-made guide yet, so message [support](/faq/support/) and we
will help you set it up.
